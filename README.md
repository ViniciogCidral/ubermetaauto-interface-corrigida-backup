# UberMetaAuto — AndroidIDE v4

Configuração compatível para API 35:
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Kotlin 1.9.24
- compileSdk/targetSdk 35
- minSdk 26
- JDK 17 (fornecido/configurado pelo AndroidIDE)

Abra a pasta que contém `settings.gradle`, `build.gradle`, `gradlew` e `app`.

Esta versão não usa `dependencyResolutionManagement()` no settings.gradle.

Antes de instalar, siga o roteiro em `TESTE_NO_CELULAR.md`.

Para compilar pelo terminal do AndroidIDE, siga `COMPILAR_NO_ANDROIDIDE.md` e
execute `bash compilar-androidide.sh` a partir da raiz do projeto.
